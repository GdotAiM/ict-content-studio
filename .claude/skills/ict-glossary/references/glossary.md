# ICT Glossary (studio's own wording)
| Term | Definition |
|------|------------|
| Liquidity | Clusters of resting orders (stops, pending entries) that price is drawn toward. |
| Buy-side liquidity (BSL) | Orders resting above highs — e.g. shorts' stop-losses and breakout buys. |
| Sell-side liquidity (SSL) | Orders resting below lows — e.g. longs' stop-losses and breakdown sells. |
| Liquidity sweep / raid | Price trades through a liquidity pool and often reverses shortly after. |
| Equal highs / lows | Two or more swing points at nearly the same price; an obvious pool of liquidity. |
| PDH / PDL | Previous day's high / low (NY session day). |
| Displacement | A fast, large-bodied move that shows strong one-sided order flow, often leaving gaps. |
| Fair Value Gap (FVG) | A three-candle pattern where candle 1's wick and candle 3's wick don't overlap, leaving an inefficient range in candle 2. |
| Order Block (OB) | The last opposing candle before a displacement move; viewed as a possible reaction zone. |
| Breaker | A failed order block that price later trades back through and may respect from the other side. |
| Balanced Price Range (BPR) | Overlap of two opposing FVGs. |
| PD array | Any premium/discount reference zone (FVG, OB, breaker, BPR, old highs/lows). |
| Premium / Discount | Above / below the 50% of a chosen dealing range. |
| Equilibrium | The 50% level of a dealing range. |
| Market Structure Shift (MSS) | A break of a recent swing point, with displacement, against the prior short-term direction. |
| Break of Structure (BOS) | A break of a swing point in the direction of the existing trend. |
| Killzone | A time window of typically higher activity (Asia, London, NY AM, NY PM). |
| NY midnight open | The price at 00:00 New York time; a daily reference for premium/discount. |
| Asia range | High/low formed approx. 20:00–00:00 ET. |
| London range | High/low formed approx. 02:00–05:00 ET. |
| Silver Bullet | A time-based study window (e.g. 10:00–11:00 ET) looking for an FVG after a liquidity sweep. |
| Power of Three (AMD) | Accumulation, manipulation, distribution — a framework for a session's shape. |
| SMT divergence | When correlated markets (e.g. NQ vs ES) disagree at a swing high/low. |
| Draw on liquidity (DOL) | The pool price is believed to be heading toward. |
| OTE | Optimal trade entry zone, a Fibonacci retracement area (approx. 62–79%). |

Time conversion: SAST = ET + 6h during EDT, + 7h during EST.
